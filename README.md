# VisualizeScene

Independent, reusable graph visualization, editing, analysis, and layout libraries with an Uno Platform workbench for desktop and WebAssembly.

## Implementation status

Development is in progress. This project targets the documented capabilities of yFiles WPF, but is not yFiles, is not affiliated with yWorks, and does not currently claim API, algorithm, or visual parity. No proprietary yFiles implementation or assets are included.

Source, reproducible validation, and an explicit capability matrix will accompany the implementation.
