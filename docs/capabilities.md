# Capability matrix

This is an implementation inventory, not a statement of yFiles parity. “Implemented” identifies code paths in this repository; validation evidence is reported separately. Public yFiles WPF documentation defines a much broader SDK surface than this initial release. There is no source, binary, API, screenshot, or algorithm-output equivalence claim.

| Area | Implemented | Boundaries / missing work |
|---|---|---|
| Graph model | Immutable node/edge/port/label records; multigraphs; directed/undirected edges; self-loops; IDs; validation; revision events | Not yFiles IGraph API-compatible; no lookup/decorator framework or arbitrary typed tag serialization |
| Editing | Bounded literal graph Find/Replace with case/word/kind/scope options, read-only ID matches and one-transaction replacement; immutable selection snapshots; indexed area queries; cancellable marquee previews; window/crossing modes; node/edge/port/label/group filters; spatial keyboard focus/navigation; touch pan/pinch and edit arbitration; inversion and neighbor expansion; deferred single-click selection; group dragging; node creation/move/resize; two-click edges; endpoint reconnection; port and independent-label dragging; bend insertion/move; modal label editing; deletion; rectangular origin-relative configurable grid with optional center/axis snapping and magnetic node/corner snapping with rendered guides; alignment; owner-aware clipboard/duplicate | No full input-mode hierarchy, lasso selection, spacing/angular guides, bend snapping or complete gesture/input-mode parity |
| History | Atomic edits; batched subtree deletion; route-value no-op detection; rollback; bounded undo/redo; one history entry per drag/layout; stale revision rejection | Snapshot history can consume substantial memory; no persistent collaborative history or operation merging |
| Groups | Nested ownership; subtree movement/removal; grouping/ungrouping; atomic selected-group toggle/expand/collapse; fit/enlarge frames to descendant node and node/port-label envelopes; visible ancestor edge projection | No navigation into group graphs, alternate collapsed sizing, folder proxy metadata or table-style group nodes |
| Ports | Relative ports; owner validation; add/select/drag/delete; inspector; endpoint reconnection with candidate feedback; shared policy for direction, capacity, degree, loops, parallel edges and cycles; immovable ports | No complete yFiles candidate/constraint API, side-allocation optimization or custom port shapes; policy configuration is application-owned, not serialized graph data |
| Labels | Node/edge captions; independent node/edge/port labels; measured hit bounds; selection, drag, nudge, rename, delete, duplicate and owner-retargeting paste; owner-aware compound movement; arc-length edge anchors; HarfBuzz shaping; multiline wrapping/truncation; bounded automatic independent-label placement with custom candidates and conflict diagnostics | No complete label-model API, label rotation, guaranteed conflict-free placement, rich text or comprehensive multilingual fallback; headless measurement is an explicit estimate unless the host supplies font metrics |
| Styles | Six node shapes; colors; strokes; arrows; group headers; selection handles | No yFiles XAML styles/templates, all arrow/line styles, image nodes, custom decorators, BPMN/UML/table/complex business styles |
| Hierarchical layout | SCC condensation; rank assignment; barycenter crossing sweeps; variable sizes; compound layout | No full incremental constraints, swimlanes, partition grids, bus structures, node/edge constraints, advanced edge bundling or yFiles-equivalent quality |
| Other layouts | Tree spanning forests; radial rings; circular; variable-size grid; seeded Barnes-Hut organic | Not all yFiles layout families; no balloon/series-parallel/orthogonal-node/compact-disk/multipage/mixed layout engines |
| Routing | Shape-accurate endpoint clipping; polyline/orthogonal paths; port-aware self-loops; manual bends; obstacle-aware orthogonal A* with clearance and bend costs | Self-loop obstacle routing unsupported; search-budget exhaustion diagnosed; no bus/spline/bundled routing or full crossing optimization |
| Analysis | BFS; weak/strong components; topological order; Dijkstra; Bellman-Ford; Kruskal forest; PageRank; unweighted Brandes; DSATUR; Edmonds-Karp flow/min-cut | Not the full yFiles analysis catalog; coloring is heuristic; no planarity, isomorphism, exact coloring, clustering or all centrality variants |
| Rendering | Uno shared Skia canvas; estimated-byte/count-bounded node/label/edge-caption picture LRU; cached five-pattern grid on the actual snapping lattice; viewport-culling for nodes, edges, labels, ports and selection adorners; retained unchanged edge paths and indexes; level-of-detail; shaped labels; selection and overview | Backend chosen by Uno host; no direct WebGPU renderer or physical-GPU performance certification; changed revisions still require nontrivial preparation; estimated picture-byte accounting is not a strict process/native/GPU-memory cap |
| Controls | GraphControl; GraphOverview; NodePalette; GraphPropertyInspector; modeless GraphSearchControl | Not WPF/yFiles drop-in controls; no complete accessibility/UI Automation graph peer tree, gesture inertia/rotation or drag/drop palette parity; physical touch devices not certified |
| Workbench | Menu/toolbar; compact staged grid settings with native preview; palette; inspector; layout/analysis/label-placement panels; selection and snapping controls; examples; responsive rails; keyboard commands | GraphEditor-inspired original UI, not screenshot-identical; no dockable workspace, multi-document tabs or original icon reproduction |
| JSON | Versioned native round trip; source-generated serialization; input-size validation | Schema is VisualizeScene-specific; no arbitrary extension payload persistence |
| GraphML | Native structured round trip; plain graph topology; groups; ports; selected legacy yWorks shape/geometry/bend data | Partial yFiles interchange only; unknown extension keys reported; specialized data/styles not retained; nesting limit 128 |
| Export | Standalone SVG with visible ports; PNG allocation guard; visible scene bounds include bends and independent labels; workbench supplies shaped font measurements; JSON; GraphML | No PDF/XPS, printing, poster tiling, multipage output or font embedding; SVG node-caption wrapping and fallback fonts are not pixel-identical to Skia |
| Platforms | Uno desktop and WebAssembly projects using the same libraries and control implementation | Only reported build/test configurations count as validated; native Windows/macOS execution and physical GPU tests must be verified independently |
| Packaging | Seven separable NuGet projects; required controls package artifact; isolated package-only consumer tests; source and browser build artifacts | Package artifacts are not the same as a release published to nuget.org; no package feed publication without explicit credentials |

## Parity validation still required

A genuine parity release would require a version-pinned yFiles WPF reference build, licensed test fixtures, an enumerated API/behavior matrix, screenshot baselines, layout-quality benchmarks, import/export round trips, accessibility tests, platform tests, performance budgets and all corresponding implementations. The current tests cover this repository's contracts, not the complete commercial SDK.

## Detailed interaction contracts

[Label placement and snapping](label-placement-and-snapping.md) describes bounded candidate refinement, captured font measurements, collision diagnostics and magnetic node/corner alignment. [Selection](selection.md) describes area geometry, item masks, immutable snapshots, cancellable previews and topology expansion. These are original implementations, not yFiles API aliases.

[Touch and keyboard navigation](navigation.md) and [performance](performance.md) document the newer contracts, reproducible benchmarks and known tradeoffs.

[Graph Find/Replace](search.md) describes the literal query, Unicode, scope, lock, budget and lifecycle contracts. Regex search, locale collation and full-text inverted indexes are not implemented.

[Grid preferences](grid-preferences.md) documents configurable grid geometry, native settings, bounded rendering and the high-zoom lattice correction.
